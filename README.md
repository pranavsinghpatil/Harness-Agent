# Harness Agent - Trueforge Hackathon

Welcome to our project repository for the [WeMakeDevs Trueforge Hackathon](https://www.wemakedevs.org/hackathons/trueforge)! 🚀

This repository is built using an [Agent Harness Architecture](https://github.com/walkinglabs/awesome-harness-engineering) tailored for a 4-person team collaborating seamlessly alongside AI coding agents.

## 📁 Repository Structure

- `backend/`: API services and business logic.
- `frontend/`: User Interface and web application.
- `configs/`: Shared configurations and environment definitions.
- `data/`: Data models and temporary datasets.
- `docs/`: Documentation and architecture diagrams.
- `experiments/`: Proof of Concepts and exploratory R&D.
- `schemas/`: Database schemas and data definitions.
- `scripts/`: Utility scripts and automation.
- `.ai/` & `.cursor/`: AI agent contexts, prompts, and tooling configs.

## 🚀 Getting Started

1. **Clone the repo:**
   ```bash
   git clone https://github.com/pranavsinghpatil/Harness-Agent.git
   cd Harness-Agent
   ```

2. **Environment Setup:**
   Copy `.env.example` to `.env` and fill in the required values.
   ```bash
   cp .env.example .env
   ```
