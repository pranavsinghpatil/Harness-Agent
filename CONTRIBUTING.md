# Contributing Guidelines

Welcome to the team! Since we are 4 members working fast for the Trueforge Hackathon, here is how we can collaborate efficiently.

## Branching Strategy
- Main branch: `main`
- Create branches for your work using the format: `feature/your-feature-name` or `fix/issue-name`.

## Commit Messages
Write clear, concise commit messages. 

## Pull Requests
1. When your feature is ready, open a PR against `main`.
2. Add a brief description of what you did and why.
3. Tag at least one other team member for review before merging.

## Working with AI Agents
- Use the `.cursorrules` to keep the AI aligned with our architecture.
- Store useful prompts or agent contexts in the `.ai/` directory so others can reuse them.
