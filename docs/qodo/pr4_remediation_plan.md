## 🛠️ Itemized Remediation Details

### 1. Security & AST Sandbox Hardening (`#1`)
- **Action:** Enhance `ControllerValidator` to traverse the complete AST and block `__import__`, `eval`, `exec`, `open`, `compile`, `getattr`, `__builtins__`, `sys`, and dunder attribute access.
- **Action:** In `DynamicControllerLoader.load_from_code`, execute code with a restricted `__builtins__` dictionary containing only safe primitives.

### 2. Controller Loading & Function Adapters (`#2`)
- **Action:** In `DynamicControllerLoader`, prioritize explicit `BaseTargetAgent` subclasses and ensure standalone functions (`step(obs, time)` or `control(obs, time)`) are wrapped in `ScriptFunctionAgentWrapper` with full sensor packet routing.

### 3. Transport Bus Channel Binding (`#3`, `#4`)
- **Action:** In `HardwareAdapter.apply_preset`, match registered channel names (`sensor.camera`, `sensor.lidar`, `sensor.imu`, `sensor.encoder`, `sensor.position`).
- **Action:** Re-apply hardware latency and scheduler compute parameters immediately after `load_scenario` inside `SandboxSession` so resets do not discard hardware presets.

### 4. Diagnostic Fidelity & Metric Precision (`#5`, `#15`)
- **Action:** In `CausalTelemetryAnalyzer`, extract ground-truth `observation_age_s` from telemetry frames instead of hardcoding `0.41s`.
- **Action:** Map `SPEED_LIMIT` and clearance violations to distinct `FailureTriggerType`s.

### 5. Evaluation Soundness & Goal Completion (`#6`, `#18`)
- **Action:** In `HarnessEvaluationResult` and `ReliabilityEvaluationLoop`, verify that a run reached the goal and completed with 0 fatal violations before certifying as safe.
- **Action:** Propagate `payload.mode` into `EvaluationRequest` inside `/evaluate-full`.

### 6. Code Splitting & Docstrings Compliance (`#7`, `#8`, `#9`, `#10`, `#11`, `#12`)
- **Action:** Refactor `AutoCodePatcher.generate_patch` and `SandboxSession.execute` into modular helper functions $\le 50$ lines.
- **Action:** Add explicit type annotations (`TOOLS_MANIFEST: List[Dict[str, Any]]`) and full Rule 2945750 docstrings across `mcp_server/server.py`.
- **Action:** Remove redundant inline comments.

### 7. Reliability & Chaos Overrides (`#13`, `#14`, `#16`, `#17`)
- **Action:** Merge `request.chaos_fault_overrides` into scenario fault schedule.
- **Action:** Return HTTP 404 on missing scenarios across REST routes and canonical tools.
- **Action:** Forward `payload.strategy` to `AutoCodePatcher.generate_patch`.
- **Action:** Retain JSON-RPC `msg_id` in MCP error responses.
